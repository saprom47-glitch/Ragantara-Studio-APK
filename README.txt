RAGANTARA STUDIO — PWA PACKAGE

File utama: index.html
Ikon: icons/icon-192.png dan icons/icon-512.png (ikon Ragantara yang terakhir disepakati)

FITUR
- Generator prompt video Ragantara V2
- Copy Prompt, Reset, Negative Prompt, versi Indonesia
- PWA manifest + service worker untuk cache/offline

CARA UJI
1. Upload seluruh isi folder ini ke repository GitHub, jaga struktur folder.
2. Aktifkan GitHub Pages pada repository (Settings > Pages).
3. Buka URL GitHub Pages dari Chrome Android, lalu menu ⋮ > Install app / Tambahkan ke layar utama.
4. Buka aplikasi sekali saat online agar file tersimpan untuk penggunaan offline.

Catatan: Service worker/PWA tidak berjalan jika membuka index.html langsung melalui file://. Dibutuhkan HTTPS (contoh GitHub Pages) untuk pemasangan PWA.
